# AZ-900: Microsoft Azure Fundamentals — Mi ruta de estudio

Repositorio donde documento mi preparación para la certificación **AZ-900 (Microsoft Azure Fundamentals)**: apuntes por dominio del examen, un registro de mis puntos débiles y preguntas de práctica.

> Los apuntes son de elaboración propia, basados en la ruta oficial de Microsoft Learn. Pueden contener errores; si encuentras alguno, abre un *issue*.

## Sobre el examen

| Dato | Detalle |
|---|---|
| Código | AZ-900 |
| Nivel | Fundamentos (no requiere experiencia previa) |
| Puntaje de aprobación | 700 / 1000 |
| Preparación oficial | [Microsoft Learn — AZ-900](https://learn.microsoft.com/es-es/credentials/certifications/azure-fundamentals/) |

| Dominio | Peso aproximado | Apuntes |
